# Свадебный сайт — Фёдор и Ирина, 21.07.2027

Одностраничный сайт-приглашение: `index.html` (тексты и графика), `style.css` (оформление и анимации),
`script.js` (логика). Посмотреть у себя: двойной клик по `index.html`.

Стиль — нарисованные антуриумы, палитра мероприятия (шалфей, олива, мох, шампань,
пудровый, пыльная роза, персик, голубые и мягкое золото). Сайт сам подстраивается
под любой экран: телефон (в том числе боком), планшет, ноутбук, большой монитор.

## Что на странице

1. **Конверт** с веточкой антуриума: нажатие — цветок приподнимается, клапан раскрывается,
   выезжает карточка с именами, затем появляется сайт (и музыка, если она добавлена).
2. **Обложка** — Wedding Day, имена, дата, букеты антуриумов по углам.
3. **Приглашение** и календарь июля, 21-е отмечено.
4. **Программа дня.**
5. **Дресс-код** — палитра по группам.
6. **Адрес** — «Хрустальный Сад», г. Москва, ул. Жужа, 37, карта и кнопка «Открыть на карте».
7. **Пожелания.**
8. **Анкета** — встроенная Google Форма, плюс запасная кнопка «Открыть анкету».
9. **Финал** — обратный отсчёт и подпись.

Если в системе посетителя отключены анимации, сайт показывается без движения.

## Google Форма

Сейчас в `index.html` (поиск: `id="google-form"`) стоит короткая ссылка `https://forms.gle/tFGab39fcvPiubak7`.
Если внутри страницы форма не отображается, возьмите ссылку для встраивания:
в Google Формах **«Отправить» → вкладка `< >`**, скопируйте адрес из `src="…"`
(он заканчивается на `/viewform?embedded=true`) и вставьте его в `src` вместо короткой.
Высота окна формы — в `style.css`: `.form-frame iframe { height: … }`.

## Музыка

Положите трек в `assets/music.mp3` — он включится при открытии конверта, появится кнопка паузы.

## Что ещё заменить

Время в программе, дату ответа на анкету, имя и телефон организатора (блок «Пожелания»).

GitHub → **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
