# Свадебный сайт — Фёдор и Ирина, 21.07.2027

Одностраничный сайт-приглашение: `index.html`, `style.css`, `script.js`.
Открыть можно просто двойным кликом по `index.html` или опубликовать на GitHub Pages
(Settings → Pages → Deploy from branch).

## Как подключить свою Google Форму

Анкета встроена прямо в страницу (блок «Анкета гостя»), гость заполняет её не уходя с сайта.

1. Создайте форму на <https://forms.google.com> (например: имя, придёте ли, с кем,
   предпочтения по напиткам, аллергии).
2. Нажмите **«Отправить»** → вкладка **`< >`** (HTML-код).
3. Скопируйте ссылку из атрибута `src="…"`. Она выглядит так:
   `https://docs.google.com/forms/d/e/1FAIpQL.../viewform?embedded=true`
4. В `index.html` найдите `id="google-form"` и замените значение `src` на вашу ссылку.
5. Если форма длинная или короткая — поправьте высоту в `style.css`
   (`.form-card iframe { height: 1400px; }`).

Редактировать вопросы можно в любой момент в Google Формах — изменения сразу
появятся на сайте, код трогать не нужно. Ответы смотрите во вкладке «Ответы»
(их можно выгрузить в Google Таблицу).

## Что ещё поменять

В `index.html` замените заглушки: название и адрес ресторана, ссылку на карту,
время в программе дня, телефоны, дату ответа на анкету. Цвета дресс-кода — в блоке `.palette`.
